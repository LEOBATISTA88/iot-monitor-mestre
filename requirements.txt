Adicione o fluxo de trabalho do GitHub Actions ao seu repositório:

No seu repositório do GitHub, crie um arquivo .yml no diretório .github/workflows; por exemplo: neon_workflow.yml.

Copie o conteúdo YAML a seguir para o seu arquivo neon_workflow.yml.

Faça o commit das suas alterações.

O fluxo de trabalho do GitHub Actions cria um novo ramo (branch) de banco de dados a cada solicitação de publicação (pull request), o qual você pode visualizar na página Branches no Console do Neon. Quando você fecha a solicitação de publicação, o ramo é excluído.
